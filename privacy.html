Privacy Policy

Effective date: 14 September 2026

No data collection No ads No accounts No chat

EduQuest is a learning adventure app for children aged 6–9, developed by Vebstudio. It is designed so that we do not collect, store, transmit, sell, or share any personal data. This policy explains what that means in practice.

1. Data we collect: none

EduQuest has no user accounts, no registration, no analytics or tracking SDKs, no advertising, no chat features, and no real-money purchases. We do not collect names, email addresses, contact details, location, photos, audio, device identifiers, or usage statistics. No data about you or your child is ever sent to us or to any third party by the app.

2. Data stored on your device only

To make the game work, EduQuest saves progress locally on your own device (in the app's local storage). This includes:

  • the hero name and avatar look chosen in the game;
  • game progress: levels, XP, coins, streaks, completed quests;
  • learning statistics shown in the parent area (play time, first-try accuracy, hints used);
  • parent settings (language, daily play limit, sound and accessibility options).

This information never leaves the device. It is not synced, backed up to our servers (we have none), or shared with anyone. The hero name is only a label inside the game — it can be anything and does not need to be a real name.

3. Children's privacy

EduQuest is built for children and follows a strict data-minimisation approach: since no personal information is collected at all, none can be misused. The app contains no social features, no external links accessible to the child, and no advertising. Settings and any future purchase options sit behind a parent gate.

4. Web hosting

The app's content is delivered as a web application hosted on GitHub Pages. Like any web host, GitHub may temporarily log standard technical request data (such as IP addresses) for security and operational purposes; this is governed by the GitHub Privacy Statement. The app itself adds no tracking on top of this, and after the first load it can work offline.

5. Deleting data

All game data can be erased at any time: use “Reset adventure” in the parent settings inside the app, or clear the app's storage / uninstall the app. Because everything is stored only on your device, deletion is immediate and complete.

6. Changes to this policy

If the app ever changes in a way that affects privacy (for example, adding online features), this policy will be updated at this address before those changes take effect, and the effective date above will change.

7. Contact

Questions about this policy: sadig.mammadov@digitup.az

Политика конфиденциальности

Дата вступления в силу: 14 сентября 2026

Данные не собираются Без рекламы Без аккаунтов Без чата

EduQuest — обучающее приключение для детей 6–9 лет, разработанное Vebstudio. Приложение устроено так, что мы не собираем, не храним, не передаём, не продаём и не разглашаем никакие персональные данные.

1. Какие данные мы собираем: никакие

В EduQuest нет аккаунтов, регистрации, аналитики и трекинга, рекламы, чатов и покупок за реальные деньги. Мы не собираем имена, адреса электронной почты, контакты, геолокацию, фото, аудио, идентификаторы устройств или статистику использования. Приложение не отправляет никакие данные о вас или вашем ребёнке ни нам, ни третьим лицам.

2. Данные, хранящиеся только на вашем устройстве

Для работы игры EduQuest сохраняет прогресс локально на вашем устройстве (в локальном хранилище приложения):

  • имя героя и внешний вид, выбранные в игре;
  • игровой прогресс: уровни, XP, монеты, серии, выполненные задания;
  • учебную статистику родительского раздела (время игры, точность с первой попытки, подсказки);
  • родительские настройки (язык, дневной лимит, звук и специальные возможности).

Эта информация не покидает устройство: не синхронизируется, не отправляется на серверы (их у нас нет) и никому не передаётся. Имя героя — лишь игровая метка; оно может быть любым и не обязано быть настоящим именем.

3. Конфиденциальность детей

EduQuest создан для детей и следует принципу минимизации данных: поскольку персональная информация не собирается вовсе, злоупотребить ею невозможно. В приложении нет социальных функций, доступных ребёнку внешних ссылок и рекламы. Настройки находятся за родительским барьером.

4. Веб-хостинг

Контент приложения доставляется как веб-приложение, размещённое на GitHub Pages. Как любой веб-хостинг, GitHub может временно записывать стандартные технические данные запросов (например, IP-адрес) в целях безопасности; это регулируется Заявлением о конфиденциальности GitHub. Само приложение не добавляет к этому никакого трекинга и после первой загрузки может работать офлайн.

5. Удаление данных

Все игровые данные можно стереть в любой момент: кнопка «Сбросить приключение» в родительских настройках приложения, либо очистка хранилища / удаление приложения. Поскольку всё хранится только на вашем устройстве, удаление происходит немедленно и полностью.

6. Изменения политики

Если приложение изменится так, что это затронет конфиденциальность (например, появятся онлайн-функции), политика будет обновлена по этому адресу до вступления изменений в силу, а дата выше изменится.
